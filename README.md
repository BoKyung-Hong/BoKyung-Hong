## 📌 주요 프로젝트

### 🏃 [RUNRUN](https://github.com/RunRun-labs) - 러닝 크루 커뮤니티 플랫폼
> 2025.12 ~ 2026.01 (2개월)

커뮤니티 플랫폼의 백엔드 개발을 맡아 크루 관리, 멤버십, 결제, 포인트 시스템을 구현했습니다.  
단순 기능 구현에 그치지 않고 데이터 흐름과 정합성을 고려하며 설계하는 것을 목표로 했습니다.

- **TossPayments 결제 연동**: 외부 API 응답값 검증 및 예외 처리로 안정적인 유료 멤버십 결제 구현
- **FIFO 포인트 시스템 설계**: 만료일과 상태값을 함께 고려한 선입선출 방식의 포인트 차감 로직 직접 설계
- **비관적 락으로 동시성 제어**: 동시 결제 상황의 데이터 충돌 방지 및 트랜잭션 관리 경험
- **Spring Scheduler 배치 처리**: 멤버십 만료 및 상태 변경 자동화 구현
- **AWS S3 파일 관리**: 이미지 업로드 및 클라우드 환경에서의 파일 저장 구현

`Java` `Spring Boot` `JPA` `PostgreSQL` `AWS S3` `TossPayments`
